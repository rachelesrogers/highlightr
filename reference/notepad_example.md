# Comment Example Dataset

Participant comments for the initial description used in the jury
perception study

## Usage

``` r
notepad_example
```

## Format

### `notepad_example`

A data frame with 126 rows and 2 columns:

- ID:

  Participant Identifier, as well as source document identifier

- Text:

  Participant notes, as well as source transcript

## Source

Jury Perception Study (see Rogers (2024)
<https://digitalcommons.unl.edu/dissertations/AAI31240449/>)
